## Project Analysis: KaamKaaj

### Overview
**KaamKaaj** is a gamified accountability platform built with **FastAPI** and **PostgreSQL**. It combines task management with RPG-style progression where users ("Khiladi" = Player) earn XP only when they prove task completion via AI-verified submissions.

---

### How It Works for Users

| Feature | Description |
|---------|-------------|
| **Registration & OTP** | Users register with email/username. Must verify via 6-digit OTP sent to email (rate-limited: 3/min) |
| **JWT Authentication** | Secure login with OAuth2 password flow; JWT tokens protect all routes |
| **Lakshya (Goals)** | Create high-level goals like "Get Fit" or "Learn Python" |
| **Kaam (Tasks)** | Add specific tasks under goals. Can mark as "requires verification" |
| **Saboot (Proof)** | Submit text or image evidence for tasks requiring verification |
| **AI Reviewer** | Google Gemini evaluates submissions - strict judgment, only approves if genuine proof provided |
| **XP & Leveling** | Each task has XP reward. Level = 1 + (total_xp // 1000). Users start at Level 1 |
| **Profile Management** | Update username, clan name, bio, delete account (with password) |

---

### Key Routes
- `/khiladi` - Registration, OTP verification, profile CRUD
- `/login` - OAuth2 JWT token generation
- `/khiladi/me/profile` - Get current user profile
- `/lakshya/khiladi/me/lakshyaBanao` - Create goals
- `/kaam/lakshya/{id}` - Create tasks under a goal
- `/kaam/{id}/submit` - Submit proof (triggers AI if verification required)
- `/dashboard` - Overview of progress
